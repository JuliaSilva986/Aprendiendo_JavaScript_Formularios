# 📝 Registro de Eventos con JavaScript

Mini proyecto desarrollado como parte del módulo de **Manejo de Formularios de DEV.F**.

## 📌 Descripción

Aplicación web que simula el registro de asistentes a eventos mediante un formulario interactivo. Permite capturar información personal, seleccionar preferencias y validar los datos ingresados utilizando JavaScript.

## ⚙️ Funcionalidades

- Registrar nombre, correo electrónico y teléfono.
- Seleccionar intereses mediante checkboxes.
- Elegir un horario utilizando botones de radio.
- Seleccionar una fecha para el evento.
- Adjuntar un archivo opcional.
- Validar los campos antes de procesar el registro.
- Mostrar mensajes personalizados de error o confirmación.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Practicar el manejo y la validación de formularios con JavaScript, utilizando distintos tipos de campos HTML y proporcionando mensajes personalizados según los datos ingresados.

**Nota:** El registro es simulado. La aplicación no envía ni almacena información en un servidor.
